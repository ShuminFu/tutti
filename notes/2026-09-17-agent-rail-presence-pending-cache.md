# 会话栏绿点闪烁：未加载 ≠ 空闲

日期：2026-09-17

## 改了什么

切换 Agent 时，会话栏那颗在线圆点会闪一下绿。原因不是圆点组件自己抖，而是：

1. 可见会话一变，宿主死活表被整批换成新回包；切回来时原会话状态已经没了。
2. 新状态还没回来时，渲染把「没有记录」当成 idle，先画绿点。
3. 宿主随后回 `closed`，绿点再被摘掉。

这次修了两处，都在 DinTalDock 的 AgentGUI：

- `agentGUIConversationPresence`：把加载中（`pending`）、不支持（`null`）、未知（`unknown`）分开。加载中不画绿点；真实空闲和运行中仍按原判据。
- `useHostSessionLiveness`：按 **工作区 + 会话** 留一份有界缓存（上限 400，当前可见 id 不驱逐）。权威回包只更新对应条目，不再整表替换。旧请求取消后既不写缓存也不刷新视图，这条保护还在。

现场是否就是会话图标右下角那颗绿点，仍待你切几个已结束会话确认。代码侧这条闪烁链路已经按计划堵住。

## 怎么确认

1. 打开一个已结束、原来会闪绿点的会话列表。
2. 切到另一个 Agent，再切回来。
3. 已结束的会话不应先闪绿再消失。
4. 真正空闲的会话仍应是绿点，正在跑的仍应是蓝点。

## 没做的

- 没有改宿主契约；`pending` 只存在于客户端视图。
- 没有做真实 GUI 验收（仓库默认不跑）。
- 报障现场是否同一颗点，仍要人工看一眼。
